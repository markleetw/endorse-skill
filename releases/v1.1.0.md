# Endorse v1.1.0 — Stronger first-draft judgment

## English

This release improves the *first completed recommendation*, especially when the relevant evidence is already available but the initial framing is too generic.

### Highlights

- Better selection of distinctive, evidence-backed narrative angles.
- More selective follow-up questions to catch overlooked responsibilities, including meaningful people-leadership evidence.
- Stronger developmental editing: remove redundant paragraphs and fix known weaknesses *before* delivery.
- Clearer English-first documentation with Taiwan Traditional Chinese localization and corrected platform installation guidance.
- Fictional evaluation scenarios, editorial rubric, contributor guidelines, and structural CI.

### Compatibility and limitations

Endorse remains a text-only Agent Skill. Host compatibility and writing quality vary by AI platform and model. Structural checks do not demonstrate prose quality; review the evaluation record before deployment. Users must independently verify factual claims before publishing.

### Installation

Download `endorse.zip` from this release and follow [README.md](https://github.com/markleetw/endorse-skill/blob/v1.1.0/README.md). This archive contains `endorse/SKILL.md` and bilingual documentation.

## 繁體中文（台灣）

此版本重點在**第一次交稿前就完成更充分的編輯判斷**：從已知的合作事實找到更有辨識度的切入點，避免只寫空泛能力標籤。

### 主要改進

- 更精準選擇具有第一手證據的敘事角度。
- 只在必要時追問可能被忽略的關鍵職責，例如工程主管的帶人方式。
- 審稿時主動刪減重複段落，修正已知可改善的問題，而不是交給使用者處理。
- 重整英文及台灣繁中說明，釐清 ChatGPT 與其他平台的安裝限制。
- 新增虛構案例回歸測試、品質評分規準與自動化結構檢查。

### 限制與安裝

Endorse 是純文字 Skill；模型與平台不同，寫作品質可能有差異。自動化結構驗證不等於已通過文字品質評估，發布前仍須由推薦人確認事實。

請從本 Release 下載 `endorse.zip`，並參考 [繁中 README](https://github.com/markleetw/endorse-skill/blob/v1.1.0/README.zh-TW.md) 安裝。
