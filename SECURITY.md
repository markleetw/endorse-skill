# Security policy

Endorse is a Markdown-based AI Agent Skill with no bundled executable code or external API integration. Security concerns may still arise from prompt injection, unsafe installation instructions, unexpected data disclosure, or compromised release artifacts.

## Reporting

Please **do not publish exploit details, personal information, or private recommendation drafts in a public issue**. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature if enabled for this repository. If that feature is unavailable, contact the repository owner privately through an independently verified channel; do not assume public GitHub issues are private.

Include: affected release/commit, supported reproduction with fictional data, expected versus actual behavior, and possible exposure. No response-time or bug-bounty guarantee is currently offered.

## Scope

We review malicious or misleading Skill instructions, package integrity, and guidance that may expose user-provided information. We do not control external AI hosts, their data handling policies, or LinkedIn.

## User privacy

Treat recommendation inputs as potentially sensitive employment information. Avoid adding real individuals, employers' unpublished projects, or personnel feedback to public fixtures and reports.
